Implementation reviewed
-----------------------
- Captured JSON and object/collection operations support copying in Windows,
  workers and AudioWorklets. Native transfer lists and serialization records
  remain separate from author data and property hooks.
- ServiceWorker.postMessage serializes before deciding whether to skip an
  event, records the incumbent sender and can start installing, waiting or
  active workers. Delivery uses ExtendableMessageEvent/messageerror and the
  normal event lifetime lease.
- Client.postMessage uses the receiver's relevant settings and a native,
  bounded container queue. startMessages, the first onmessage assignment,
  DOMContentLoaded and dedicated/shared-worker startup enable delivery at
  their specified points. Each MessageEvent runs as its own task.
- Empty DOM-only hosts tolerate presentation clientState notifications.
  The host-boundary inventory is 270. Frame-geometry expectations now allow
  the implemented Pointer Events compatibility-mouse transition grouping.

Corrections made during this review
-----------------------------------
1. Borrowed methods now operate on the receiver's worker and container.
   Previously, a parent Window's postMessage method could silently address its
   own empty worker map when called with a child's ServiceWorker object.
   Borrowed startMessages/onmessage similarly enabled the wrong queue. Private
   records now carry their native operation and queue-enabling function, while
   ServiceWorker.postMessage still records the incumbent sender separately.
2. Serialized transfers retain native ownership until delivery finishes or is
   abandoned. A guard releases unclaimed holders after stale-receiver errors,
   failed sends/startup, worker exit, cancellation before an async task starts,
   partial deserialization, or recipient teardown. Already-claimed ports stay
   valid. Client delivery explicitly finishes ownership in a finally block.
3. Recursive discard drains the complete queued transfer graph. The previous
   1,024-packet cut-off could leave the remainder allocated. The registry's
   endpoint/byte bounds still apply; removing an endpoint returns its queue
   only once. A regression follows 1,100 links to a final OffscreenCanvas.
