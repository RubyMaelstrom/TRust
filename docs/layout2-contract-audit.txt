# Layout2 lifecycle and conformance audit

This is an implementation/verification ledger, not a claim of complete CSS
conformance. A faster warm layout is acceptable only if its geometry, scrolling,
painting, hit testing and synchronous DOM observations remain correct. An
optimization budget may discard optional cached results; it must not discard
content or silently change selector truth.

## Contract ledger

| Boundary | Required contract | Audit / implementation state |
| --- | --- | --- |
| Attribute → selector subject | Follow combinators and logical dependencies; preserve former matches on removal | Compiled forward/inverse dependency paths; `:has()` anchors and filtered sibling ranks; differential and retention tests added |
| Selector subject → computed values | Explicit inheritance and custom properties can propagate through descendants | Coalesced subtree retirement; still conservative for unchanged computed outcomes |
| Computed-value storage | Missing differs from cached absence; node retirement is local; font epochs remain valid | Node-owned sparse value rows with indexed property lookup; GC and container-query invalidation integrated |
| Child-list → selectors | Adjacency, positions, emptiness, reparenting, relational predicates | Existing dependency guards retained; complex relational/state structures still have broad fallback |
| Shadow scopes / slot distribution | Selector scoping and flat-tree inheritance are distinct relations | Existing correct conservative fallback retained; scope-bearing selective paths remain open |
| Stateful controls | CSS state, IDL state, reset/default state and radio associations agree | Checked selector invalidation localized; dirty checkedness/selectedness native-state contract remains open |
| Style / rule changes | Source order, media, layers, inheritance and registrations remain authoritative | Global stylesheet epochs retained; full interaction audit not yet complete |
| Transitions | Before/after styles, endpoint invalidation and sampled presentation stay coherent | Dirty-target endpoint transactions retain independent values in place; container queries/units now invalidate endpoints without a DOM mutation; incremental/full comparison and 16/1,024-sibling work-bound tests |
| Container queries / units | Observe even false queries; settle before geometry escapes | Existing axis-aware read graph retained; node-owned value retirement integrated; cycle/fallback review open |
| Formatting tree | Anonymous boxes, lists, generated content and inherited inline context survive reuse | Immutable sharing and counter input/output keys retained; broader conformance gaps remain |
| Fragment constraints | Parent makes placement decisions; margins, floats, dimensions and positioned descendants are inputs | Existing complete-key checks and cold equivalence suite retained; no new assumption of independent layout |
| Resource inputs | Fonts, intrinsic image metadata and SVG resources invalidate all actual consumers | Per-result shared read sets for image-size inputs, including missing reads, nested cache-hit replay and bounded unique allocation accounting; resource completion preserves DOM/style/formatting-tree state. Negative/arrival/resize/removal, CSSOM and paint tests pass. Global font/SVG metadata expiration and whole-map comparison remain open |
| Optional cache retention | Bounded metadata and payload, predictable victim selection, no stale references | Constant-time expected recency bookkeeping; formatting cache now accounts shared allocations with first-retain/final-release ownership edges; fragment-cache accounting remains conservative |
| Synchronous geometry | CSSOM reads see current layout; rendering may consume the same immutable fragments | Actor-owned retained measurement remains authoritative; display:contents no longer receives fabricated descendant rectangles. Lazy snapshot-owned border-box index eliminates repeated whole-fragment scans, preserves multi-fragment/table fallbacks and accounts storage; fragmented inline client-rectangle projection remains incomplete |
| Coordinate spaces | Client rectangles apply accumulated transforms; offset/client metrics ignore transforms; scrolling overflow includes before/after bounds | Typed retained 2D transforms now serve graphics, client geometry, overflow and the terminal projection; normal-flow positions stay untransformed. Nine core independent coordinate cases pass with matched scrollbar policy. Projective 3D, inline fragment identities and live scroll/sticky projection remain open |
| Document roots and nested viewports | Every Document retains its root box and independent formatting context; root margins never collapse | Root margin pre-addition removed; context boundaries seal child margins at both ends. Child HTML boxes preserved in canonical and serialized layouts, with root display blockification and native viewport resize synchronization. Focused canonical/snapshot/client/offset coverage added; broad verification ongoing |
| Graphical / terminal output | Shared CSS-pixel geometry, one terminal quantization, matching hit tests | Cold comparison covers boxes, tracks, scroll extents, painting and terminal rows; broad independent-browser differential coverage remains open |
| Relational matching | No arbitrary visit cutoff may produce a false match result | Removed the 8,192-candidate truth-changing cutoff; >10,000-candidate regression added |
| Table structure | Correct groups, spans, nesting and anonymous fixup without area-proportional storage | Removed depth fallback/span-product clamp; row-group zero spans, numeric parsing, first-header/footer ordering and ghost-track merging implemented; focused tests and Chromium differential pass |
| Box generation versus paint | Clipping, opacity, zero area and offscreen placement do not remove boxes | Removed clipped/screen-reader-only/zero-size suppression and media-wrapper sibling deletion; geometry, clipping and authored-poster ordering regressions pass; UA display/content-visibility and other hard-coded tree omissions still require review |
| Other formatting / fragmentation | Flex, grid, floats, inline/bidi, writing modes, overflow, replaced content, positioning | Existing tests are a baseline, not evidence of exhaustive standards coverage; full audit remains open |
| Scheduling / presentation | No idle spin; no repeated authoritative DOM/layout copies | Existing shared actor/frontend contracts retained; desktop acceptance must be measured separately |

## Steam menu regression (2026-09-27)

Artifacts: `target/steam-menu-regression-20260927-IPziFXF4/`.

- Reproduced the reported disappearance and unreleased scroll lock with the
  actual release desktop browser, native pointer events and private Wayland
  sessions. The installed desktop and pass 7b open Special Sections correctly;
  passes 8k and 9g clip away the entire menu. User sessions were untouched.
- Cause: corrected scrolling-area geometry exposes overflowing descendants of
  a zero-height sticky wrapper. CSSOM incorrectly returned an empty string for
  its unspecified overflow-y. The author's scroll-lock predicate consequently
  treated that visible-overflow wrapper as a scroll container and applied
  overflow:hidden to it as well as the viewport. Clipping the dismissal controls
  then left the viewport lock unreleased. This is a TRust contract defect, not
  a website-specific exception or a reason to suppress valid overflow geometry.
- Causal control: overriding only missing computed overflow values to `visible`
  in the unchanged failing release restores the menu. The production correction
  supplies the normative initial values at the CSSOM boundary; it contains no
  site identifiers, selector exceptions or author-script modifications.

## Native external-playback controls and retained point-hit index (2026-09-27)

Artifacts: `target/mpv-overlay-20260927-tH01iCpZ/`. README and installed
executables remain unchanged; this is a development release, not a promotion.

- The earlier removal of media-wrapper sibling deletion was correct for CSS
  box generation but exposed a presentation regression: opaque authored posters
  covered the external-playback affordance. Do not reinstate sibling deletion
  or assign a huge author z-index. HTML #the-video-element explicitly permits
  representation by an external playback utility, and #focusable-area gives
  UA subwidgets a media-element DOM anchor (local HTML snapshot e5071a20c856).
  Sources: /big/web-standards/repositories/whatwg/html/source:37347 and :86020,
  https://html.spec.whatwg.org/multipage/media.html#the-video-element and
  https://html.spec.whatwg.org/multipage/interaction.html#focusable-area.
  The snapshot was fetched 2026-09-06, not refreshed against upstream here.
- Graphical paint now retains a separate browser-media spatial program. The
  desktop/headless browser UI composes it after all page layers and before
  browser chrome; CSSOM never includes it. Native activation wins over authored
  overlays, while scrollports, visibility, inertness, transforms, and source
  changes remain effective. Focus order includes the eligible native subwidget
  at its DOM anchor, honoring tabindex and shadow scopes. This does not change
  TRust's existing Tab/COMMAND shortcut policy.
- Terminal controls have an explicit item kind, separate from author text
  collision recovery. They paint after inline images and fixed layers and use
  the same scroll/carousel mapping for input. Selecting the underlying media
  hit box highlights the visible button. Poster pixels and authored siblings
  remain; controls add no layout row or geometry change.
- The new fixture `src/fixtures/media_overlay.html` covers an opaque poster,
  transformed nested scroller, source-less video, and a full-page fixed cover.
  Native release input verifies exact direct/page fallback URLs and originating
  referrers through a private test-only mpv argument recorder. No real playback
  capability is claimed. Final screenshots show both controls above the opaque
  cover. Private sessions were closed without touching the user's desktop.
- Steam's Special Sections and Ways to Play panels remain visible. Toggle and
  backdrop dismissal allow native scrolling and reopening. Auto selection uses
  CPU in the private compositor; this is not Hybrid site acceptance. The
  scripted Recommendations click retained Browse content in both the pre-index
  and final comparison; do not count it as an independently passed menu switch.
- CSSOM point queries previously constructed and cloned an entire Scene, then
  copied the active clip stack for every region on every call. `PageHitIndex`
  compiles one immutable paint transaction into shared dynamic coordinate
  spaces, clip-parent nodes, and median-partitioned local-space BVHs. Queries
  sample current scroll/sticky/animation properties, search local bounds, check
  exact shapes/transforms, and return unique elements in reverse paint order.
  Static boxes and indexes survive scrolling; actual paint/geometry invalidation
  replaces them. The geometry cache accounts for retained index allocations.
- Local normative sources: CSSWG snapshot 81c27f686901, CSSOM View §5
  #dom-document-elementsfrompoint, CSS Transforms 1 #transform-rendering,
  CSS Overflow 3 #scrolling, CSS Position 3 #stickypos-insets. Independent clip
  and transform stacks are preserved, including a clip outliving its transform.
  Under /big/web-standards/repositories/w3c/csswg-drafts/, the consulted source
